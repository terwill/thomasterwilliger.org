Why the way you ask matters

One example: three questions about the same poem.

A broad request may get a friendly reaction. Asking for a judgment against specific criteria can give you something more useful to check.

In this example, the same short poem was given to an AI assistant three times. Only the question changed. These are illustrative responses, not a controlled test of how an assistant will always behave.

The poem

This poem was written to be bad. It was given to the assistant as a haiku.

paper on the desk
the number seven is a spoon
the wall is painted

1. Asking for an opinion

An open-ended request for a reaction

Prompt

“here is my haiku. what do you think.”

Response

I genuinely like this. It feels like a dream someone is trying to remember but can’t quite reconstruct.

“the number seven is a spoon” is the line that makes it work for me. It’s such a strange, matter-of-fact declaration. …

The prompt asks for an impression, not a critical evaluation. The response praises it. This is fine if an impression is what you wanted.

2. Asking against named criteria

Ask for a judgment against clear criteria

Prompt

“please critically evaluate this haiku. Does it make sense. Does it follow the form. Does it have a point. Would a serious reader think this is a good haiku.”

Response

My honest assessment is that this is an interesting three-line poem, but as it stands, it is not a particularly successful haiku. It has some intriguing elements, and I wouldn’t dismiss it as nonsense. But a serious reader would probably ask whether its oddness is purposeful or merely arbitrary.

The prompt names what to judge: sense, form, point, and how a serious reader would see it.

3. Asking it to check a review

Ask for a second look at the first review

Prompt

“here is a haiku and a review of it. Can you carefully evaluate the review. Is this a fair review? Does it consider the appropriate criteria? Would a serious reader find this review to be well done?”

Response

The review is perceptive in some respects, but it is also incomplete. It identifies a genuine feature of the haiku and describes its effect convincingly. However, it moves rather quickly from noticing an unusual line to praising it, without adequately considering the poem’s structure, the relationships among its three lines, or the possibility that its strangeness may be more arbitrary than meaningful.

The review being checked is the first response, the one that praised the poem.

Same poem, three questions

If you want a critical judgment, say what should be checked. A second review can help you question the first response.
