Guided Workflow

Ready-to-use prompts for planning, checking, and understanding work.

You may have a question to sort out, a document to write, or a project to finish. An AI assistant can help, but you need to be able to follow its reasoning, judge its advice, and check the result.

Guided Workflow gives you a small set of ready-to-use prompts: messages that tell the assistant how to help. They ask it to use plain English, explain choices, do useful checks, and keep the work manageable. You describe what you want and decide what to do with the result.

Suppose you have a report that is difficult to read. Use Fix machine-written text to revise it. If a passage is unclear, ask a Helper to explain it. If the report matters, ask a Reviewer for a second look.

For code changes in a Git project, see Guided Coding.

Getting started

  1. Open a prompt below and read what it asks the assistant to do.
  2. Click Copy prompt, paste it into your AI chat, and add your question, goal, or files before sending.
  3. Start with one prompt. Ask for an explanation or a review later if it would help.

There is nothing to install. You can use these prompts in your usual AI chat.

These prompts ask the assistant to work this way. They cannot make it do so, so check important results yourself or ask for a review.
