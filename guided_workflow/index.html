Guided Workflow

Ready-to-use prompts for understanding, planning, writing, and reviewing work with an AI assistant.

Guided Workflow is a collection of ready-to-use prompts: messages you can paste into ChatGPT, Claude, or another AI chat. They ask the assistant to explain choices, check important work, and tell you what remains uncertain. You choose the task and make the important decisions.

Use them when you want to understand something, complete a project, improve a document, or review a result. For a casual question, an ordinary AI chat may be enough. There is nothing to install. For code changes in a Git project, see Guided Coding.

For example, if an AI has started work and you cannot follow what it is doing, or asks you to approve something you do not understand, try Help me understand (see a real example). If an AI-written report sounds unnatural, try Fix machine-written text.

How to use a prompt

  1. Open the prompt for your task and read what it asks the assistant to do.
  2. Click Copy prompt. Paste it into your usual AI chat, add your question, goal, or files, and send it. Share only material you are comfortable sending to that service.
  3. Read the result. Ask follow-up questions, or use a separate review when the result is important. A separate review can catch mistakes, but it can also miss them or agree with a wrong answer.

The prompts are instructions, not guarantees. The assistant can still make mistakes, so check important results yourself. You can use one prompt now and another later; there is no setup to maintain.

Related approaches

Many people have developed ways to get better results from AI assistants. Guided Workflow brings a few of these ideas together in nine ready-to-copy prompts for everyday tasks.

  • ChatGPT Custom Instructions and Claude Projects let you give an assistant standing instructions about how to respond.
  • Ethan and Lilach Mollick's prompt library offers prompts for teaching and other work.
  • Humanizer edits text that sounds machine-written, using Wikipedia's guide to the signs of AI writing.
  • LLM Council is a more technical tool that asks several AI models and has them assess each other's answers.

Guided Workflow is not a replacement for these. It is a small collection you can use with the AI assistant you already have. We have not measured whether these prompts improve accuracy or clarity more than other methods.
