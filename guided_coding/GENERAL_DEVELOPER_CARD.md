# Guided Coding setup card for your project

This card is optional. Give it to Claude with `/guided_coding setup` in the Git project you want to change. It suggests what to check; your project's instructions and your decisions determine the actual settings.

Read the project's documentation, build scripts, configuration and saved settings first. Recover information that is already there. Ask me only for missing information that affects the work.

Find and explain:

- Which repository to work in, any related repositories and the existing project instructions.
- How to build and test the program, including the commands, their folders and the required shell, Python or compiler environment.
- Which tests check this task and which wider tests the project requires.
- Where temporary work and lasting task records should go.
- Which existing checks and protections must stay enabled.
- Servers, automated tests and resource limits, if this project needs them. Leave these for later when they are not needed yet.

Show me the complete proposed settings and instruction changes before saving them. Follow Guided Coding's required save and recovery procedure. After an approved save, check the saved files and explain anything unfinished.

Setup by itself does not start a coding task, connect to a server or publish changes. This card supplies no account details, passwords, API keys, server access or permissions. It does not replace Guided Coding's instructions.
