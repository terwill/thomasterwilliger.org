# Why Guided Coding and not Vibe Coding?

Vibe coding is when you tell an AI what you want and the AI writes all the code for you. What could possibly go wrong? A lot can go wrong. The AI may misunderstand what you want. It may write code that does not do what it claims. It may write no tests, so you cannot tell whether the code works. You may have no idea what the code does.

Guided Coding aims to keep you in control while making code writing with an AI easy. It guides you and the AI through a fixed set of steps. You agree on a plan and see what the AI will do. The AI builds or fixes the code and writes tests. Reviewer agents check the work. Then the AI presents the work for your approval. See the [User Guide](getting-started.html) for how to use Guided Coding and the [Installation page](index.html#install) for how to install it.
