# Why Guided Coding and not Vibe Coding?

Vibe coding is when you tell an AI what you want and the AI writes all the code for you. What could possibly go wrong? A lot can go wrong. The AI may misunderstand what you want. It may write code that does not do what it claims. It may write no tests, so you cannot tell whether the code works. You may have no idea what the code does.

Guided Coding keeps you in control while making code writing with an AI easy. For every change, the AI writes a test that proves the fix where that is feasible, runs a review pass, prepares an outside review for hard changes, and gives you a short report of what changed, what was checked and what was not. It fixes real defects in the code it changes, asks before changing interfaces, defaults or behaviour that other code relies on, and it never pushes or installs anything without your word. The two rules that matter most are yours: ask until you understand each change, and stay in control.
