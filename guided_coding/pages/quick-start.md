# Quick Start with Guided Coding

If you already have Claude Code, it is easy to install and use Guided Coding. Just open a new session in Claude Code and give it these instructions to tell you about Guided Coding and to walk you through setting it up and running it.

```copy
Instructions to Claude Code for setting up Guided Coding. Read the instructions and documentation of Guided Coding at https://www.thomasterwilliger.org/guided_coding/. Briefly summarize how Guided Coding works and tell me whether Guided Coding can help me with my workflow. If Guided Coding appears useful, read the installation details and offer to install it on my computer and show me how to use it. If I approve, suggest a location to install on my computer and do the download, checksum and registration in this conversation, asking my approval before each change. Then tell me when I must open a new conversation, which folder to open it in, and what to send there. When installation is complete, offer to start me on a small test case. Be sure to make it clear what installation steps you can carry out so that I don't have to do any more than necessary. Use plain declarative sentences and present all the information I need to make decisions in a clear way. Ask for my approval of all actions that change anything on my computer. Whenever you hand off to me, put the complete steps I must do next in your final message, even if you already listed them earlier. Do not refer me to earlier messages. When you tell me to open a new conversation, give click-by-click directions for the Claude app’s Code tab: the Environment choice (Local → My computer) and the separate folder selector at the bottom of the page. Before giving me directions, check my operating system. On a Mac, give the Claude app steps (with the Cmd+Shift+G folder step) and mention the Terminal alternative. On Linux, give Terminal steps (cd to the folder, then claude). On Windows, tell me Guided Coding is not supported on Windows, explain what it needs, and ask how I want to proceed. Before you tell me what a Guided Coding step will show or ask, read the kit’s own procedure and screen files for that step (for example payload/SETUP.md and payload/screens/). Describe what I will actually see, say where to find it (the approval box versus the conversation text above it), and tell me exactly what to check before approving. If you have not read the relevant file, say that your description is unverified.
```
