# Quick Start with Guided Coding

**New to Claude Code?** Guided Coding runs inside it, so install Claude Code first: follow [Anthropic's Claude Code quickstart](https://code.claude.com/docs/en/quickstart), which also explains the account you need, then come back here.

**Already have Claude Code?** Then this is the easiest way to install Guided Coding. Open a new session in Claude Code, in the folder where you keep your software, and give it these instructions. Claude will explain Guided Coding, install it with you, and start you on a small task.

```copy
Instructions to Claude Code for setting up Guided Coding. Read https://www.thomasterwilliger.org/guided_coding/ and the installation page https://www.thomasterwilliger.org/guided_coding/getting-started.html. Briefly summarize how Guided Coding works, including its two main rules (ask until you understand each change; I stay in control), and tell me whether it can help with my work. If it can, offer to install it. Suggest where to clone the repository, then use the installation page's commands, which check before they change anything. Before changing anything on my computer, show me all the installation steps, say what each does, and ask for my approval once; then run them, and ask again only if something unexpected comes up. Then tell me when I must open a new conversation, which folder to open it in, and what to type there (`/gc`, then optionally `/gc setup`). Give click-by-click directions for the Claude app's Code tab: the Environment choice (Local, then My computer) and the separate folder selector at the bottom of the page; on a Mac mention Cmd+Shift+G, and mention the Terminal alternative (cd to the folder, then claude). If the app looks different from this, say so and describe what to look for. When installation is complete, suggest a small first task. Use plain sentences, and put every step I must take next in your final message.
```

Installing is once per computer. Afterwards, open Claude Code in the folder of the project you want to change and type `/gc` followed by what you want done. `/gc setup` is optional, once per project, and saves that project's build and test commands. Guided Coding has been tested on macOS; it should work on Linux, and has not been tested on Windows. To install it yourself instead, see [Installing Guided Coding](getting-started.html).
