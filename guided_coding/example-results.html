1. A box that overlaps the map by one plane keeps that plane

Problem

Boxing a non-wrapping map with bounds that overlap it by exactly one grid plane gave a box of zeros.

Cause

get_bounds_of_valid_region marks the region empty with last_valid <= first_valid. With a one-plane overlap the first and last valid planes are the same, so a region of one plane counted as empty, and the whole box was zeroed.

Fix: how it solves the problem

The test is now last_valid < first_valid: a region is empty only when its last plane is before its first.

Essential code

    if last_valid <  first_valid:
      some_valid_points = False
